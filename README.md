# OxidizeChat 🦀

**🚧 현재 공사 중입니다. (Under Construction)**

Rust의 강력한 메모리 안전성과 Tokio 라이브러리의 비동기 처리 능력을 활용한 실시간 채팅 서버입니다. Rust의 백엔드 성능을 경험하기 위해서 만들어 보았습니다.

*This is a real-time chat server leveraging Rust's powerful memory safety and the asynchronous processing capabilities of the Tokio runtime. I developed this project to experience and explore the backend performance of Rust.*

## 🛠️ Tech Stack
* **Language:** Rust (Edition 2021)
* **Runtime:** Tokio (Asynchronous I/O)
* **Deployment:** Render (Cloud PaaS)

## 🔗 How to Connect
터미널에서 아래 명령어를 입력하여 접속할 수 있습니다.
*You can connect to the server by running the command below in your terminal.*

nc [Render-Server-URL] [Port]
